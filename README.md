# Astra Server

Host Minecraft servers on your own Windows PC — Vanilla, Paper, Purpur, Folia, Fabric, Quilt, Forge, NeoForge,
Velocity, Waterfall and Bedrock. Astra Server downloads the server and the right Java for you, and gives you a live
console, file manager, plugins/mods/modpacks (Modrinth, Hangar, CurseForge), backups, schedules, a health check,
a performance dashboard, public access without port forwarding (playit.gg / e4mc), and a Discord bot.

## Download
Go to **[Releases](https://github.com/Ahere12/Astra-Server-Releases/releases/latest)** and download
`Astra-Server-Setup-<version>.exe`, then run it (Windows 10/11, 64-bit).

Windows SmartScreen may warn because the installer isn't code-signed yet: click **More info → Run anyway**.

## Updates
From version 0.3.1 on, Astra Server updates itself: it checks this page when it starts and every 6 hours, downloads
new versions in the background, verifies them, and installs when you press **Restart & update**.

## Discord bot
See [DISCORD.md](DISCORD.md).

Your servers, worlds, backups and settings are stored in `%APPDATA%\AstraServer` and are kept when you update.
